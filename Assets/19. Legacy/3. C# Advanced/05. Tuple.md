# Tuple?
여러 값을 하나의 단위로 묶어서
다루는 경량 데이터 구조. 크게
`ValueTuple`과 `레거시 Tuple Class`로 
나뉘는데 보통 `ValueTuple`을 의미 합니다.

## 1. 기본 문법

```csharp
// var 키워드를 입력해서 타입 추론으로 튜플을
// 사용하는 법
var position = (10f, 10f, 10f);
Debug.Log($"{position.Item1}, {position.Item2}, {position.Item3}");
// 10.000, 10.000, 10.000 출력

// 명명된 튜플(Named Tuple)을 사용하는 법
var position = (x : 10f, y : 10f, z : 10f);
Debug.Log($"{position.x}, {position.y}, {position.z}");

(float x, float y, float z) position = (10f,10f,10f);
Debug.Log($"{position.x}, {position.y}, {position.z}");


```
주로 타입 정의가 필요 없는 임시 객체를 정의해야할 때 사용합니다.
메서드의 반환값으로도 사용할 수 있어서 여러 반환값을 통제해야할 때 사용합니다.
해당 객체는 반환되면 변경될 수 없습니다.
