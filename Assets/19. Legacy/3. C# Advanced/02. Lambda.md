# Lambda (람다식)
`이름 없는 즉석 함수`. 짧은 함수를 그 자리에서
바로 써 넣는다

---

## 람다식?
이름을 붙여 따로 선언하지 않고, `(입력) => 결과`
형태로 그 자리에서 만드는 델리게이트에 넘길
짧은 함수를 간결하게 쓸 때 주로 쓴다.
> 재사용성이 낮은 함수들을 간결하게 표현할때 많이 사용함.  
> 혹은 너무 자주 사용되지만 함수로 만들기에는 짧은 함수를 표현 할 때
> 사용.

## 상황
```csharp
void Start()
{
    button.onClick.AddListener(OnClickStart);
    // 델리게이트에 구독자를 추가하기위해 함수를
    // 대입함
}

void OnClickStart() // 딱한줄인데 별도 메서드로 떨어져있음
{
    Debug.Log("시작!")
}
```
한두 줄짜리 콜백까지 이름 붙은 메서드로 만들면,
코드가 흩어지고 장황해짐.

## 적용
`=>`로 `그 자리에서` 함수를 만들어서 넘긴다.

```csharp
void Start()
{
    // 이름 없는 함수를 즉석으로 등록
    // (입력) => {내용;} : {}는 한줄이면 생략 가능
    button.onClick.AddListener( () => Debug.Log("시작") );
    
    // 입력이 있는 람다
    player.OnHpChanged += 
        (hp, max) => hpBar.Setvalue(hp / (float)max);
    
    // 여러 줄이면 {} 사용
    button.OnClick.AddListener(() => 
    {
        Debug.Log("클릭");
        Play();
    });
}

```
`짧은 콜백`을 사용하거나, `짧은 로직`을 사용해야할 떄
코드가 한곳에 모이고 간결해진다.
`비동기 처리`할 때 `처리 흐름`이 한눈에 보인다
