# Delegate(델리게이트) + Null 조건부 연산자
**함수를 변수처럼 담고 전달하는 문법**
여러 함수를 등록해 한꺼번에 호출할 수 있다.

---

## Delegate ?
델리게이트는 `함수를 가리키는 변수`이다. 값 대신
`함수 (메서드)`를 담아 두었다가 나중에 호출한다.

여러 함수를 `+=`로 등록하면, 한 번의 호출로 등록된
함수 전부가 실행 된다.

> 유튜버 구독 + 알림 설정하면 모든 구독자들에게
> 알림이 오는것과 같은 내용입니다.

## 상황
Observer를 인터페이스로 만들면 `구독자`, `인터페이스`,
`리스트`, `통지` 함수등을 매번 만들어야 했다.
> ActionPlatformer의 CombatSystem 내용 보면 됨
```csharp
public interface IHpObserver
{ void OnHpChanged(int hp, int max); }

private List<IHpObserver> observers = new();

public void Subscribe(IHpObserver o) 
{...}

private void Notify()
{
    for(int i = 0 ; i < observers.Count; ++i)
    {
        observers[i].OnHpChanged(hp, max);
    }
    // .... 이런 느낌?
}
```
> 통지해야하는 기능을 만들 때마다 위의 내용을
> 반복해서 구현해야 한다.

## 적용
`Action<T>`(반환 없는 함수용 델리게이트)과
`event`로 같은 구조를 몇 줄로 줄인다.
```csharp
public class Player
{
    // event? : 밖에서 호출(발동)은 못하고, 
    // 구독(+=)/해제(-=)만 허용하는
    // 안전한 델리게이트
    public event Action<int, int> OnHpChanged;
    
    public void TakeDamage(int dmg)
    {
        hp -= dmg;
        OnHpChanged?.Invoke(hp, maxHp);
        // ?. : null이 아닐경우를 체크할 수 있는
        // null 조건부 연산자
        // 여기서는 OnHpChanged의 구독자가 
        // 없을경우(null일 경우) 건너뛴다
    }
}

// 구독하는 쪽 코드
// : 인터페이스 구현 없이, 함수를 그냥 등록한다
player.OnHpChanged += hpBar.Refresh; // += 로 구독
player.OnHpChanged += sound.PlayerHurt;
player.OnHpChanged -= hpBar.Refresh; // -= 로 구독 해제

```

### Null 조건부 연산자 `?.`, `??`
- `{A}?.{B}` : A가 null이 아닐경우 B를 실행한다. A가 null일 경우 건너 뛴다
    - `OnHpChanged?.Invoke(hp, maxHp);` : OnHpChanged가 null이 아니라면 구독자들의 함수를 실행한다
- `{A} ?? {B}` : `a`가 `null`이면 `b`를 사용한다.
  - `name ?? "이름없음"` : name 변수가 null이면 "이름없음"을 사용
